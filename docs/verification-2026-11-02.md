## Mutation-invariant review

| 不变量 | 组合变异 | 预期与观察 |
| --- | --- | --- |
| 旧记录不能因导入消失 | v1/v3/v4 备份、重复文章/段落、既有单词状态与旧备份冲突 | 合并取并集；既有单词自评保留；新练习按事件 ID 去重。测试通过 |
| 无效备份不得部分写入 | 有效词汇 + 非法文章索引、无效时间、事件冲突、未知版本、超过 50,000 个事件、原型键 | 全部验证后再写入；拒绝时存储不变。测试通过 |
| 存储失败不得显示已保存 | 中途写入抛配额错误；损坏本地 JSON | 合并写入回滚测试通过；损坏存储出现可见恢复提示，提供原件导出 |
| 提示和自评不能制造客观掌握 | 先看答案再填对、先看迁移参考再选独立、角色过程中看过提示、重复提交 | 辅助练习与独立回忆分开，表达仍为自评；同题重复提交只保存一次。测试通过 |
| 间隔不能被重复练习刷大 | 同日多次答对、答错后当日再答对、跨日答对、提示后答对 | 同日不连续升间隔；失败/提示回到巩固。测试通过 |
| 未完成音频不能记听完 | 播放后取消、切页后迟到 onend、无语音 API、完整回调序列 | 取消/失效回调零听完记录；完整序列一次记录。页面状态测试使用受控语音依赖，通过 |
| 录音不能在离开后继续占用麦克风 | 拒绝权限、正常停止、录音中切页 | 拒绝后按钮恢复；原生 MediaRecorder 测试中停止/切页音轨 ended，临时 URL 被清理 |
| 同一来源两标签的记录不能相互覆盖 | 两个实际浏览器标签并发写不同练习 | 支持 Web Locks 的 Chromium 保留两个事件。测试通过 |
| 用户文本不得作为 HTML 执行 | 表达中输入带 onerror 的 HTML，再打开历史记录 | 页面转义为文本，无生成的图片/事件处理器。浏览器检查通过 |

## 已知边界

- 未在真实麦克风上评价音质，也未人工听辨各设备的英文合成音色；浏览器录音启停用测试音源验证。语音回调的错误/取消检查不等同于音质验收。
- 未在真实 iOS Safari、Android 或 Firefox 上运行；已验证 Chromium 的桌面与手机尺寸。旧浏览器不支持 Web Locks 时应避免多标签同时练习。
- 无账号/云同步，记录以浏览器来源为边界；直接文件模式与本机服务/线上域名之间需要备份迁移。
- 不提供自由表达自动评分或发音测评。303 个用法条目不是全部英语词义，也不是已掌握词汇数。
- 此次没有线上部署，线上状态不在验收范围。
