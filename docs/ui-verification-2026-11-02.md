## Mutation-invariant review

| 必须保持的行为 | 变化组合与预期 | 观察结果与证据 |
| --- | --- | --- |
| 文章为主要学习入口，历史内容和记录不漂移 | 首页进入、题材筛选、空搜索后清除、旧稿/精编切换；原 20 篇及旧记录不被 UI 修改 | 首页主按钮仍进入文章；清除后恢复 40 篇精编；旧稿 20 篇可访问；原稿指纹测试通过；旧 `sr_completed`、`sr_practiced` 值保持 |
| 视觉切换不丢草稿，不新增学习证据 | 桌面及手机先填写未保存复述，再在正文与理解区域间切换 | 输入保留，`sr_learning_v1` 不因切换变化；UI 检查通过 |
| 播放位置、按钮与实际调用一致 | 选择第三段后播放、停止、再次起播；循环/速度设置；文章流程中的取消与错误 | 受控语音接到第三段文本；停止后显示第三段位置；取消/失败不伪造听完；UI 及文章流程检查通过 |
| 手机控件可操作且不遮挡主要内容 | 窄屏 + 译文 + 词典弹层 + 固定播放器；目录开关及键盘操作 | 各测试宽度无页面横向溢出，词典边界高于播放器；目录关闭后退出视口，入口状态与焦点同步 |
| 同一操作有一致的键盘和视觉反馈 | 阅读区域方向键、设置打开/关闭/Escape、正文词汇 Enter/Escape | 当前区域、展开状态、字号值同步；关闭设置返回入口焦点；键盘词典可开关 |

发现并修复：手机目录使用的状态类不一致导致显示/关闭异常；词典浮层可能落在播放器后方；选中段落被播放清理动作重置；已移除菜单的旧 Escape 逻辑仍访问空节点。修复后重跑相关检查并通过。

## 未覆盖范围

- 未在真实 iPhone/Android、Safari 与各系统音色上验收。自动化中的受控语音只用于验证状态和调用，不证明声音自然度或真实录音质量。
- 未操作用户浏览器中的已有学习记录；自动化使用隔离浏览器数据。历史数据保护由固定样本、备份回归及数据路径审查验证。
- 未增加云账号、联网翻译或人工语音；离线字体和原创 SVG 资源不依赖外站。

建议实机体验重点：系统语音、麦克风授权、软键盘弹出后的复述输入及浏览器底栏收起时的播放器位置。
