# 文章内容与主线优化：检查记录

2026-11-02，Asia/Shanghai。当前本地版本；未发布线上。

## 实质变化

使用者校正为**文章为主**。今日阅读推荐文章，主按钮进入阅读器，文章库是主要内容入口。词汇专题、复习及短对话辅助文章学习，短对话不再占据首页推荐。

文章库默认包含 40 篇精编稿，另有 20 篇历史原稿：

| 内容 | 数量 |
| --- | --- |
| 原 20 个主题的独立重写 | 20 篇 |
| 较长人物/工作访谈（虚构教学情境） | 10 篇 |
| 新增日常、旅行、工作与问题解决文章 | 10 篇 |
| 精编英文词次 | 13,964（非独立单词数） |
| 中英对齐段落 | 240 组 |
| 文章表达讲解 | 160 组（不声称互不重复） |
| 具体理解题 | 80 道 |
| 复述任务 / 换条件表达任务 | 各 40 个 |

精编稿每篇约 308–389 词，语言按基础、中级、进阶作编辑提示。源数据 `editorial-data.js`；完整双语材料同步导出到 `Shadow-Reading-English-Materials.md`。

## 内容编辑检查

逐篇检查具体事件是否清楚、叙述是否推进、语言点是否在正文出现、理解题是否能从文中回答，以及中文是否对齐时间/数字/动作。

本轮修正的例子：

- 早晨故事原理解题把叙述者提议的午餐误写成邻居的邀请，已改为询问周五实际约定。
- 夹克故事明确区分商品价差与额外交通/时间成本，避免用商品价差冒充总支出差额。
- 科学测试段落补充被忽略的浇水条件，保持结论与可观察证据一致。
- 160 组语言点均关联正文实际词形；例如 `take for granted` 对应原文 `taken for granted`。
- 历史稿 4、9、11、12、14、16、17、19、20 的中英段落数不一致。为保留历史对象不覆盖原文，阅读器标出可能错位并引导进入同主题精编稿；新稿全部六段逐一对齐。
- 虚构访谈明确标为原创教学情境，不冒称真人采访。图表、报价和资金示例注明具体口径，不把示例条款写成通行法律或理财建议。

## Mutation-invariant review

| 不变量 | 变异与预期 | 观察 |
| --- | --- | --- |
| 历史文字和学习对象不漂移 | 为全部旧稿保存内容指纹；新稿只追加，原 ID 1–20 和段落保留 | 20 篇 SHA-256 指纹全部一致 |
| 改写文字不能继承旧学习结果 | 先保存原稿 1/20 的完成标记与原稿 1 的第 3/5 段，再进入重写稿 21 | 新稿无原完成/段落标记，旧稿标记保留 |
| 新旧导航不误入另一集合 | 新稿第一篇/末篇、旧稿末篇，上一/下一边界及直接深链接 | 精编 1/40 与原稿 1/20 分开；旧链接原篇原段不变 |
| 文章问题必须绑定当前文章 | 答错后修改、切换文章、最后一篇目标 | 问题本轮核对正确，切篇更新，没有陈旧目标或答案 |
| 答题/自评不能变成掌握证明 | 两题全对；看迁移参考后选独立；存复述后切篇再回来 | 理解题不写文章完成；迁移按借助提示保存；复述按文章 ID 恢复 |
| 取消旧播放不能继续读新文章 | 开始播放、切篇、手动触发旧语音 onend | 无新语音，无旧完成结果写入；跟读语音错误不自动跳入成功流程 |
| 手机能完成文章任务 | 320/390px、长标题、理解题英文、复述表单 | 无页面溢出；表单和按钮可用 |
| 导出正文和页面不能分叉 | 从同一 JS 数据生成材料文档 | 40 篇、240 对齐段、160 语言点和 80 题来自同一数据源 |

## 限制

语言与任务经过本轮逐篇编辑检查，尚未由独立母语编辑或学习者验证。自动检查不能证明所有措辞都达到出版水平或保证学习效果。浏览器语音仍为设备合成；录音/音色的真实硬件质量不在这次内容验收范围。线上版本未更新。
