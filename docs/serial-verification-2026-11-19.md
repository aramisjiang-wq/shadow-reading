# 连载与 5200 词计划验证

日期：2026-11-19。项目版本：5.0.0。本地实现与发布包已验证，未推送或发布到线上。

## 内容与范围

- 新增 43 集原创双语连载《枫树街的夏天》，九章、七位固定人物，ID 61–103。
- 6946 个英文词次；172 组双语段落、172 个搭配、86 道理解题；每集有复述与迁移任务。
- 旧 40 篇精编独立文章和 20 篇历史原稿归档，文字、索引、原学习记录不被覆盖。
- 5200 个唯一词典基础词条，各有释义、实际语料例句、词形和原作者署名。其中 3232 条提供中文例句译文，其余只提供英文例句和词条释义。
- 按当前词形匹配规则，43 集正文识别到目标库中的 938 个词条。其余由拓展词库提供练习，不能把全部 5200 宣称为正文覆盖量。
- 词库由 ECDICT 词频与基础词条标记筛选，匹配 ManyThings/Tatoeba 例句；不是某个官方 5200 词考试大纲。中文释义未按每个例句人工消歧，语料未逐句人工审校。

## 能力记录

看过、听完不产生独立回忆证据。语境回忆按原句词形匹配，可能拒绝其他语义合理答案。查看完整例句当天按辅助练习记录，跨刷新保留；同日重复不跳级。

“多日回忆保留”要求当前连续阶段至少三级，且首末成功回忆相隔至少七天；单纯等待七天不达标。失败或辅助回忆会重置阶段。

“回忆 + 迁移自评达标”另需至少两个日期、两个生活场景的独立表达自评。自由表达只核查目标词、最低长度和是否照抄；没有语义、语法或口语评分。因此此栏不是语言能力认证，也不保证读完连载即可熟练使用 5200 词。

- `npm test`：24 项通过，包括旧文指纹、全部新剧集、5200 词去重与例句匹配、七天跨度、辅助记录降级和 26000 条记录的压缩及备份往返。
- `npm run build`：成功，30 个运行文件，包含完整材料和必要许可证。
- 发布包 `/dist/` 子目录浏览器检查：原辅助练习 46 项、旧文章兼容 40 项、界面 87 项、新连载与词库 41 项，共 214 项，无页面异常。
- 新检查包含第一/末集、前情、词库分页搜索、空白拒绝、照抄拒绝、跨刷新提示降级、场景草稿、等待锁保存时切换页面，以及 320/390/768 像素宽度。
- 人工检查了首页与手机阅读截图。语音仍为设备合成；未新增真人录音或自动口语评测。

## 数据与容量

统一学习记录继续兼容旧 JSON；大于 50 万字符后使用本地 LZ-String 压缩。完整导出仍为普通 JSON，三个入口统一支持 40MB 以内导入。学习事件数量上限仍为 50000；浏览器配额异常会显示保存失败，不把未保存的行为计为完成。

来源快照 SHA-256 在 `vocabulary-data.js`；许可证在 `licenses/`。重建脚本不在运行时联网，发布包不包含源语料压缩包。
