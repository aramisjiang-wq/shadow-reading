# UI 案例调研与改版依据

日期：2026-11-02。目标场景：使用者围绕英语文章完成听读、跟读、查词、理解、复述和间隔复习。

这里的“优秀案例”是基于场景匹配度的设计选择，不是客观榜单。查阅公开的一手页面、官方说明和可访问的官方界面图片；没有注册账户或声称完成各产品登录版验收。

## 当前页面的主要问题

1. 首页的大装饰区与多组零值统计占据空间，阅读预览较弱。
2. 首页、旧阅读器和文章单词本的配色、字体、图标与控件外观不一致。
3. 阅读器顶部工具过多，手机底部有另一套控件；显示译文、音色和字号的入口分散。
4. 正文与全部读后任务同时铺开，长页面难以辨认当前阶段。
5. 桌面目录移动到小屏时缺少一致的开关、焦点与筛选反馈；词典浮层需要为播放器留位置。

## 改版方案

- 以阅读应用而非宣传页组织首页：继续阅读、正文开头预览、题材入口与精选条目。
- 一套暖白/墨色/绿色主题贯通所有页面，搭配本地可用的衬线正文和无衬线界面字体。取消远程字体依赖。
- 原创题材线稿帮助识别文章，不使用来源不清的案例截图或品牌素材作为产品资源。
- 内容库以图形缩略图、中文标题、英文标题、难度和篇幅构成可扫描条目，筛选无结果时可清除。
- 阅读器正文保持约 60–70 字符的舒适行宽，原文、译文与段落按钮层次分明。
- 正文 / 语言点 / 理解与复述分区切换，保留同一篇已输入草稿；查看辅助区域不新增成绩。
- 一套播放器适配桌面和手机，提供播放/暂停、停止、段落导航、循环与速度；段落条表示位置，不冒充音频时间轴。
- 字号、音色、主题和专注模式集中到阅读设置；手机目录支持搜索、版本筛选、关闭和键盘焦点回到入口。

## 范围与取舍

没有引入账号、订阅、云端 AI 语音或新的掌握算法。文章编号、原文、备份格式和学习状态语义保留。没有将竞品的功能说明当成本项目已实现的能力；本次实现与验证见 UI 检查记录。
