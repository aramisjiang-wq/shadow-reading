# Shadow Reading 系统学习升级 Implementation Plan

**Goal:** 用场景对话与词汇用法课程，帮助使用者从辨认英文走到听懂、准确回忆和独立表达；学习记录必须如实反映证据。

**Architecture:** 保留原 20 篇文章及其索引、词汇与历史存储键，原阅读器迁至 reading.html。新首页使用本地静态课程数据、共享存储与独立练习界面；无需账号或外部 API。

**Tech Stack:** 原生 HTML、CSS、JavaScript，Web Speech API，本地存储；Node 内容/状态测试与浏览器操作验证。

## 已确认方向

- 40 个原创生活/工作对话，分级、分场景，提供双语、语言点、听写、角色接话和迁移表达。
- 按词汇的词义、变形、搭配和句型建立课程。覆盖动词、数词、数量、形容词、时间、介词与其他基础表达。
- 浏览器合成朗读明确标识，不冒充真人录音；不声称严格 CEFR 测评或覆盖所有英语词义。
- 不用播放次数或自评制造掌握结论；开放表达以参考答案和自评保存，不自动判分。

## Task 1: 内容与共享状态

创建 curriculum-data.js、learning-core.js。每个词条提供中文义项、示例/译文、搭配/易错点、一个可客观核验的回忆题。每单元另设用法题；每对话有角色台词、语言点、迁移任务。建立跨课程引用、内容唯一性和答案检查。

新记录采用稳定 ID。复习以本地日期和练习证据调度，显示到期量；同题同日重复不连续增加复习间隔。导入先验证整个备份，再合并；保留历史词条和旧版本备份兼容，不删除旧记录。存储不可用、损坏备份和跨标签变化必须可见并可恢复。

## Task 2: 学习工作台

创建新 index.html、learning.css、learning-app.js。提供首页、对话目录、课程目录、词汇检索、复习和进度/备份入口；支持手机、键盘、明暗主题。课程筛选与搜索结合，深链接可直达课程和对话。

## Task 3: 闭环练习

实现可停止的逐句朗读、隐藏原文听写、分角色留白接话、替换表达、自评与本地录音回放。所有异步语音/录音在离开或切换练习时清理，取消播放不增加听完证据。听写看答案后不记独立答对，开放表达不自动评分。到期词条按回忆题练习并更新复习。

## Task 4: 旧版衔接与说明

保留 reading.html、words.html 的既有能力；提供返回新版导航和兼容旧深链接。修正文档中未经核实的 7000+ 单词及“尚雯婕影子阅读法”归因。新增使用说明与内容边界，更新完整备份入口。

## Task 5: 验证与最终审查

运行课程引用/重复/答案检查、备份旧新版本/无效输入/合并测试、复习日期边界测试；浏览器验证首页、筛选、对话听写、角色/表达、课程回忆、复习、刷新恢复、导入导出、旧页面、手机尺寸与控制台错误。

关键不变量：旧记录不丢失；无效导入零写入；看过答案不算独立回忆；自评不等于客观掌握；取消/切换/无语音不能假报播放成功；复习间隔不能被同日重复或重试刷大。
