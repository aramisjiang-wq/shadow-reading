# 文章内容扩充与精编 Implementation Plan

**Goal:** 增加可用于精听、跟读和复述的阅读内容，以自然英文、具体信息、分级长度、准确双语和可检查的学习任务提升文章本身质量。

**用户校正：** 以文章为学习主线。首页推荐文章，导航以文章库为核心；词汇与复习支撑文章学习。长访谈是文章体裁，短对话仅作为次要补充练习，不再占据首页主推荐。

**Architecture:** 原 articles-data.js 的前 20 篇及其文字、段落、ID 完整保留。新 editorial-data.js 追加 40 篇：20 个原主题的重写稿、10 篇长访谈、10 篇日常/工作叙事。重写稿有 revisionOf 关系，新旧练习不会共用文章索引。

**Tech Stack:** 原生 JavaScript 数据与现有阅读器、工作台；Node 内容检查、Playwright 阅读流程验证。

## 内容标准

- 原创教学文本，虚构人物和场景，不冒充新闻、真人采访或生产案例。
- 每篇有具体情境、信息变化和明确结果/待解决问题；避免通篇抽象定义、重复结论和为了难度堆砌生词。
- 参考篇幅：基础约 300–350 词，中级约 300–380 词，进阶约 340–400 词。难度为编辑判断而非标准测评。
- 六个中英对齐段落；访谈每段为一个完整问答。双语中的时间、数字、人物和因果一致。
- 每篇 4 个搭配/表达讲解、2 个具体理解题、1 个复述任务、1 个换条件表达任务。

## 实施

1. 建立原稿内容指纹，编辑 40 篇文章及其教学字段，校验新旧 ID、段落对齐、长度、重复和引用。
2. 工作台默认显示精编稿，可按题材、文体、难度搜索筛选；历史原稿可单独进入，数量分别显示。
3. 阅读器新增阅读目标、语言点、理解题及复述/迁移任务；理解题仅显示本轮结果，不写入“掌握”。读取重写稿时可回原稿，原稿也能进入重写稿。
4. 原文单词本纳入新增文章，并按新 ID 回原文；旧有词汇/文章/段落记录保持原义。
5. 同步阅读材料清单、使用说明和检查记录。验证新稿不继承旧完成状态/段落标记、旧深链接不漂移、最后一篇可正常阅读、手机无溢出。

## 验收边界

自动检查证明结构与数据一致性，不等于母语编辑审定或学习效果验证。内容进行逐篇编辑检查，语言质量仍可随实际使用反馈继续修订。本次授权为本地内容与页面优化，未包含线上发布。
